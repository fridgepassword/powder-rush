# Powder Rush

A downhill skiing game that runs in your browser — one HTML file, no install.

**To play:** download `index.html` and open it in any modern browser (Chrome, Edge, Firefox, Safari). Works on desktop and phones.

## Maps
- **Pine Valley** — forest run with slalom gates, logs, moguls and ice
- **Terrain Park** — kickers, gap jumps, XL kickers, rails, kinked & rainbow rails, tubes, boxes, hoops and P-A-R-K letters
- **Glacier Pass** — slick ice, crevasses and frozen spires
- **Deep Glades** — deep-powder tree skiing: duck low branches, thread tight gaps, escape tree wells, link powder turns
- **Midnight Woods** — ski by lantern light and headlamp

## Modes & difficulty
- **Avalanche** — outrun the slide; crashes cost time
- **Free Ride** — no avalanche, crash and keep going
- **One Life** — one crash ends the run
- **Easy / Normal / Pro** — Easy saves near-miss landings; Pro is strict but pays ×1.3. Avalanche and One Life on Normal or Pro pay **2×** for tricks off jumps and rails.

## Controls
| | Keyboard |
|---|---|
| Steer | `A` / `D` |
| Tuck / brake | `S` / `W` |
| Jump | `Space` |
| Spin (air) | `←` / `→` |
| Front / back flip (air) | `↑` / `↓` |
| Grab (air) | hold `W` `A` `S` `D` — two at once for combo grabs |
| Rails | `A` / `D` balance, hold `←` / `→` to slide, `Space` to pop |
| Pause / mute | `Esc` / `M` |

Touch: hold left/right to steer (spin in the air), hold the middle to tuck (grab in the air), swipe up to jump, swipe up/down in the air to flip.

## Extras
Power-ups (Magnet, Shield, Boost, 2× Points, Ghost), smashable snowmen, wildlife, rival skiers, missions, a combo timer, and a **Shop** where snowflakes buy outfits, skis, tree styles, snow colours, trails and weather.
